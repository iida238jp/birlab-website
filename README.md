# BIRLab website

Bilingual static website for the Bio-Inspired Robotics Laboratory.

- English: `index.html`
- Japanese: `jp.html`
- Publications: `publications.html` / `publications-jp.html`
- Members: `members.html` / `members-jp.html`
- Project archive: `projects.html` / `projects-jp.html`
- GitHub Pages: deployed automatically from `main` by `.github/workflows/pages.yml`

All core site assets are stored locally, including the official BIRL logo and responsive image variants. Project records are maintained in `projects-data.js`. Open `index.html` directly or serve the repository root with any static web server.
