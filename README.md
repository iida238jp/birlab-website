# BIRL minimal website prototype

A static, responsive, single-page prototype for the Bio-Inspired Robotics Laboratory. No build process or framework required.

## Preview
Open `index.html` in a browser or run `python3 -m http.server 8000` in this folder.

## Before publication
- Confirm official affiliation and contact email (`info@birlab.org` is an unverified placeholder).
- Add verified research photos/video and links to selected publications.
- Verify PI and team details, and add a real people directory if desired.
- Confirm any approved institutional branding.

## Deploy
Upload `index.html` and `style.css` to any static web host, or deploy this directory through GitHub Pages, Netlify, or Vercel. This prototype has **not** been deployed or pushed to GitHub.
