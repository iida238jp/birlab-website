# BIRL legacy refresh

This folder is a self-contained experimental clone of the website currently
served from the repository root. It is the safe working area for the
“original-site-structure, updated-content” redesign.

- The deployed site at the repository root remains unchanged.
- GitHub Pages configuration remains unchanged.
- Pages, shared styles and scripts, project data, and required image assets are
  copied into this folder.
- Internal page and asset references remain relative, so the clone works from
  this subfolder. External links continue to point to their original targets.

Start with `index.html` for English or `jp.html` for Japanese. Future redesign
work should be made inside this folder until it is ready for a separate review
and deployment decision.
